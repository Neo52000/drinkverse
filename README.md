# DrinkVerse

Application Flutter de simulation de boissons interactives.

## Démarrage local

1. Cloner le dépôt :

```powershell
git clone https://github.com/Neo52000/drinkverse.git
cd drinkverse
```

2. Générer la structure Flutter standard dans le dépôt :

```powershell
flutter create . --platforms=android,ios,web,windows
```

3. Installer les dépendances et vérifier le projet :

```powershell
flutter pub get
flutter analyze
```

4. Lancer sur un appareil détecté :

```powershell
flutter devices
flutter run
```
